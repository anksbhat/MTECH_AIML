## 1. Problem Understanding

This assignment implements two linear neural networks from scratch, each using a single
output neuron: one for regression and one for binary classification.

**Part A - Regression.** Dataset: a NEMO ocean model grid file in NetCDF4 format
(`114549.nc4`), a self-describing binary format for large scientific grids. It stores the
longitude/latitude of every cell in a 332 x 362 ocean grid, a land-sea mask, and seafloor
depth. Task: **predict seafloor depth from longitude and latitude** (sea cells only).

**Part B - Classification.** Dataset: CSV recordings of accelerometer/gyroscope readings
from an Arduino board performing gestures (circle, idle, left-right, up-down). Each
recording is sliced into one-second windows, summarised with simple statistics. Task:
**predict whether the device is moving or idle**, given one window of sensor readings.

---

## 2. Algorithm Explanation

Both parts use the same building block: a neuron computing `z = w . x + b`. They differ in
what happens to `z` next and how error is measured.

**Part A:** `y_hat = w . x + b` (no activation, raw sum is the prediction). Loss: Mean
Squared Error, `L = (1/n) * sum((y_i - y_hat_i)^2)`. Optimiser: **Batch Gradient Descent**
- every epoch computes predictions for the whole training set at once, then updates
`w`/`b` using the average gradient (`grad_w = (2/n) X^T.(y_hat-y)`). Setup: 10,000 sampled
sea cells, 80/20 split, `StandardScaler`, learning rate 0.1, 500 epochs.

**Part B:** `z = w . x + b`, then sigmoid activation `sigmoid(z) = 1/(1+e^-z)`. Decision
rule: predict 1 if `sigmoid(z) >= 0.5`. Loss: Binary Cross-Entropy. Optimiser:
**Stochastic Gradient Descent** - updates `w`/`b` after every single training example
(`error = y_hat - y`, `grad_w = error * x`), reshuffled each epoch. Setup: 1,763 training /
533 testing windows (30 features each), `StandardScaler`, learning rate 0.01, 50 epochs.

Batch GD gives a smooth, stable curve, ideal for the small 2-feature regression problem.
SGD updates far more often, converging faster on the larger 30-feature classification
problem, at the cost of a noisier loss curve.

## 3. Results and Observations

**Part A - Regression**

| Metric | Value |
|---|---|
| Test MSE | 2,802,875.43 |
| Test MAE | 1,343.21 meters |
| Test R-squared | 0.0657 |

Learned weights: `w_longitude = -207.05`, `w_latitude = -405.43`, `b = 3503.18` (scaled
space). The loss curve converges within ~50 epochs. R-squared is low because the ocean
floor is highly irregular (trenches, shelves) and a single linear neuron with two inputs
can only fit a flat plane through it, capturing the broad global trend but not local
detail. This is the expected, honest outcome for the simplest possible linear model.

**Part B - Classification**

| Metric | Value |
|---|---|
| Accuracy | 0.9606 |
| Precision | 1.0000 |
| Recall | 0.9521 |
| F1 Score | 0.9754 |

Loss drops from ~0.31 to ~0.07 over 50 epochs. The confusion matrix shows very few
mistakes and zero false positives. This works well because "moving" windows have clearly
larger standard deviation/energy in their sensor readings than "idle" windows, making the
two classes close to linearly separable, which suits a single neuron well.

**Conclusion.** The same neuron structure (weighted sum + bias) solved classification
almost perfectly and gave an honest, interpretable baseline for the harder regression
task. Only the activation function and loss function differ between the two parts.
